# Gold (XAU/USD) 15m FVG AI Assistant

A Streamlit web app that detects Fair Value Gaps (FVGs) on 15m candlestick charts using YOLOv8, and provides trading analysis with Google Gemini AI.

## Files
- `streamlit_app.py`: Main Streamlit application
- `requirements.txt`: Python dependencies
- `notes.txt`: Trading strategy and confirmation rules
- `best.pt`: Trained YOLOv8 model weights
